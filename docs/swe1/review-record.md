# 검토 기록 — SWE.1 SW 요구사항

| 항목 | 내용 |
|---|---|
| 문서 ID | SWE1-REV |
| 검토 대상 | SWE1-SRS, SWE1-QRY, SWE1-UC, SWE1-TRC (초안) |
| 상위 입력 | OEM-SWR-001 Rev 1.0 5장(요구사항), 6장(인터페이스), 9장(추적성) |
| 검토 방식 | 작성자와 분리된 독립 검토 (별도 AI 에이전트, 작성자 판단을 전달하지 않음) |
| 검토 관점 | 수용기준 반영, 요구사항 간 모순(특히 ASIL B 무력화), 검증 가능성, 양방향 추적, 가정·질의 정합 |
| 검토일 | 2026-11-26 |
| 결과 | 1차 32건(높음 7, 중간 15, 낮음 10), 2차 재확인에서 부분 해소 6건과 신규 8건. 모두 반영 또는 질의로 처리 |

실제 사람의 서명이 아니며, OEM 승인을 뜻하지 않는다.

## 발견 사항과 처리

| RV-02 | 높음 | QM 규칙(시동 OFF, 화재·성인)이 ASIL B 접근위험 잠금을 이김 | 반영: 설계 원칙 P-1, ASIL B 규칙을 모두 QM 위로. 화재 우선 여부는 질의 | 1.1절, 1.3절, SWR-017, 020, Q-01a, Q-01b |
| RV-03 | 높음 | 공급자 가정 PENDING이 ASIL B 접근위험 잠금을 막음 | 반영: PENDING은 QM 잠금 전환만 막음 | SWR-008, A-04 |
| RV-04 | 높음 | PENDING이 순위 규칙이라 해제·운전자 unlock까지 막는 모순 | 반영: PENDING을 순위 7~9 결과에만 걸리는 필터로 정의 | SWR-008, 019 |

| RV-10 | 중간 | sensor fault 중 충돌 처리 미질의 | 반영: 가정 부여, 질의 추가 | A-16, Q-01c |
| RV-11 | 중간 | FAULT·DEGRADED 복귀 조건 없음 | 반영 | SWR-013, 021, A-07, A-16 |

## 2차 재확인

1차 개정본을 같은 검토자가 다시 확인했다. 26건 해소, 6건 부분 해소, 신규 8건이었다. 1차 기록에서 RV-01을 "반영"으로 적었으나 실제로는 충돌 신호에만 반영된 부분 반영이었다(RV-40).

| ID | 심각도 | 요지 | 처리 | 반영 위치 |
|---|---|---|---|---|
| RV-01 (부분) | 높음 | QM 신호 오류가 여전히 접근위험·sensor fault 판정을 막음. `crash_status` 자체 오류 처리 없음 | 반영: 신호 등급(ASIL B / QM) 도입. QM 신호 오류는 순위 5로 내려 순위 1~4를 막지 않음. `crash_status` 오류는 ASIL B 신호 오류(순위 2) | 1.2절, 1.4절, SWR-013, A-21 |
| RV-05 (부분) | 중간 | 스냅샷 없는 주기의 신호 값, 명령 시각 미정 | 반영: 직전 유효 스냅샷 값 사용, 명령 시각은 쓰는 스냅샷의 타임스탬프 | 1.2절, SWR-022, A-02 |
| RV-15 (부분) | 중간 | 결정표가 SWE.3에 있어 G1에서 검증 기준 불성립 | 반영: 부록 A 결정표(D-01~45, P-01~10)를 SWR 문서에 포함. 규칙 정의에서 생성해 손 오기를 막음 | 부록 A, SWR-019 |
| RV-17 (부분) | 낮음 | 같은 평가 안의 중복 `unlock`의 재입력 해석이 갈림 | 반영: 재입력으로 보지 않음 | SWR-006, A-13 |
| RV-20 (부분) | 중간 | ASIL B 규칙끼리의 조합 질의 없음 | 반영: Q-01f(SR-002↔SR-004), Q-01g(SR-002↔SR-003) | oem-queries.md |
| RV-21 (부분) | 중간 | 지연된 `CONFIRMED`의 수용기준 판정 불가, 나이 상한 없음 | 반영: 나이 1.0초 상한(A-14), 300 ms 기준은 나이 0.200초 이하 스냅샷에 한정 | SWR-007, Q-04 |
| RV-33 | 중간 | `CRASH_PENDING`의 이유 비교 순위 없음 | 반영: 막은 규칙의 순위로 비교 | 1.4절 |
| RV-34 | 중간 | state별 성립 조건 없음 | 반영: state 성립 조건 표 | 1.3절 |
| RV-35 | 낮음 | 래치 중 순위 2의 이유코드 단정 | 반영: 순위 1 쪽은 `CRASH_CONFIRMED` 명시 | SWR-013 ⑥ |
| RV-36 | 낮음 | SWR-004가 자동 잠금과 독립적으로 검증되지 않음 | 반영: override 차속 조건(접근위험 + 3.0 km/h + 재입력) 시나리오 추가 | SWR-004 |
| RV-37 | 낮음 | SWR-017 "유지·재판정" 모호 | 반영: 입력 복귀 후 규칙 미적용, 다른 규칙 없으면 `NO_CHANGE` | SWR-017, A-17 |
| RV-38 | 낮음 | 미래 타임스탬프 허용 오차 없음 | 반영: 0.050초 | SWR-013, A-22 |
| RV-39 | 낮음 | `PENDING` 고착 시 자동 잠금 무력화 | 반영: 필터 최대 2.0초, 질의 | SWR-008, A-23, Q-04 |
| RV-40 | 높음 | 1차 기록의 RV-01 처리 상태가 실제와 불일치 | 반영: 이 절에 정정 기록 | 이 문서 |

## 3차 재확인

2차 14건은 모두 해소되었다. 부록 A 결정표 55행 중 54행이 본문과 일치했고, 남은 3건을 아래와 같이 반영했다. ASIL B 규칙(순위 1~4)이 QM 규칙(순위 5~10)에 밀리는 행은 없음을 확인했다.

| ID | 심각도 | 요지 | 처리 | 반영 위치 |
|---|---|---|---|---|
| RV-41 | 중간 | D-19(sensor fault + QM 오류 → `DEGRADED`)와 SWR-021의 "`state=FAULT`" 단정이 불일치. SWR-020도 같은 성격 | 반영: 두 SWR의 state 문구를 "1.3절 성립 조건에 따름"으로 통일 | SWR-020, SWR-021 |
| RV-42 | 낮음 | Q-01의 절 번호 참조 오류 | 반영: 1.4절 순위 표와 부록 A | oem-queries.md |
| RV-43 | 낮음 | ASIL B override 차속 조건이 QM SWR-004에 있음 | 반영: SWR-006으로 이동, SWR-004는 일반 `unlock`만 | SWR-004, SWR-006 |

검토 종료. 3차 지적 3건은 반영 후 작성자가 확인했고, 검토자의 추가 재확인은 받지 않았다(문구 정정 수준의 변경).
