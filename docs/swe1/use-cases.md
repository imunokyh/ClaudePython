# Use Case — 전자식 차일드락 제어 SW

| 항목 | 내용 |
|---|---|
| 문서 ID | SWE1-UC |
| 행위자 | 운전자, 차량(신호 공급), 시험자(Web 시뮬레이터) |

| ID | Use Case | 행위자 | 주 흐름 | 관련 SWR |
|---|---|---|---|---|
| UC-01 | 운전자가 후석 차일드락을 잠그거나 푼다 | 운전자 | 정차 중 물리 버튼·AVN·음성·앱으로 좌/우/전체 `lock`·`unlock` → 선택한 쪽 출력 변경 | SWR-001, 002, 004 |
| UC-02 | 주행을 시작하면 자동으로 잠긴다 | 차량 | 차속 3.0 km/h 이상 → 좌·우 `LOCK` | SWR-003 |
| UC-03 | 후측방 접근위험이 있으면 해제를 막는다 | 차량, 운전자 | 위험 `true` → 해당 쪽 `LOCK`, `unlock` 억제 → 10초 이내 재입력 시 override 해제 | SWR-005, 006, 009 |
| UC-04 | 충돌하면 긴급 해제한다 | 차량 | `CONFIRMED` → 300 ms 이내 좌·우 `RELEASE`, 시동 OFF까지 유지 / `PENDING` 중 QM 잠금 전환 보류 | SWR-007, 008 |
| UC-05 | 화재·과온·성인 탑승 시 강제 해제한다 | 차량 | 해당 신호 `TRUE` → 좌·우 `RELEASE` | SWR-017 |
| UC-06 | 카시트(ISOFIX)가 연결되면 그 쪽을 잠근다 | 차량 | `isofix_<side>` `TRUE` → 해당 쪽 `LOCK` | SWR-018 |
| UC-07 | 시동을 끄면 해제한다 | 차량 | `ignition_on=FALSE` → 좌·우 `RELEASE`, `OFF` | SWR-020 |
| UC-08 | 입력 이상·센서 고장 시 안전하게 처리한다 | 차량 | 50 ms마다 평가 → 오류·지연·입력 끊김 → `DEGRADED`, sensor fault → 출력 유지 `FAULT` | SWR-013, 021, 022 |
| UC-09 | 현재 상태와 최근 결정을 확인한다 | 시험자 | `GET /status`, 이벤트 조회 → 출력, 상태, 이유코드, 최근 100건 | SWR-010, 011, 012, 014, 015 |
| UC-10 | 같은 시나리오를 재생해 결과를 비교한다 | 시험자 | 고정 시계로 입력 벡터 재생 → 결과 해시 비교 | SWR-016 |

여러 규칙이 겹치는 경우는 SWR-019 우선순위 표를 따른다.
