## 2. 질의하지 않기로 한 항목

| 항목 | 판단 |
|---|---|
| FR-001의 음성·모바일 앱 경로와 4장 "금지하는 해석" | 4장은 Tesla 공개 매뉴얼을 근거로 "Tesla가 앱·음성 제어를 지원한다"고 주장하지 말라는 뜻이다. 가상 OEM-A의 FR-001과 충돌하지 않으므로 FR-001대로 네 source를 처리한다. (개발 계획 검토 때 충돌로 보았던 판단을 정정함) |
| HTTP 거절 계층 (A-19) | 공급자 설계 결정이다. ASIL B 입력 검사가 Web 경로에서도 관측되도록 내용 검사를 평가 경로로 보낸다. |
