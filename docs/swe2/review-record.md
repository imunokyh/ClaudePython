## 재확인

개정본을 같은 검토자가 다시 확인했다. 21건 해소, 2건 부분 해소(AR-01, AR-09), 신규 7건이었다. 모두 아래와 같이 반영했다. 이 반영분은 작성자가 확인했고, 검토자의 추가 재확인은 받지 않았다.

| ID | 심각도 | 요지 | 처리 | 반영 위치 |
|---|---|---|---|---|
| AR-01 (부분) | 중간 | 시뮬레이션 모드에서 시각을 누가 넣는지 불명확 | 반영: Web 앱은 항상 `MonotonicClock`, `ScriptedClock`은 시험 하니스만. web의 `ScriptedClock` 사용을 SA-7로 검사 | ARC 2.1, 2.4, SAP SA-7 |
| AR-09 (부분) | 중간 | `RawInput`이 DR-7 위반, 우편함 대기 중 원시 객체 변경 가능 | 반영: `submit` 시점에 runner가 `freeze_raw`로 깊은 불변 변환, `RawInput` 필드를 불변 구조로 정의 | ARC 2.1, 2.3, 2.4 |
| AR-24 | 중간 | 한 주기 다중 스냅샷 규칙 없음 | 반영(요구사항 개정): `CONFIRMED` 우선 후 최신 1개, 명령 누적, 버린 수 기록 | SRS SWR-022, A-25, ARC 2.1 |
| AR-25 | 중간 | 시각 오류 평가에서도 crash 판정 | 반영(요구사항 개정): 시각 오류 평가는 상태 갱신 생략, 기존 래치 유지 | SRS SWR-022, ARC 3장 |
| AR-26 | 중간 | 시각이 튄 뒤 복귀 불가, 결정표에 없음 | 반영(요구사항 개정): 직전 정상 시각은 정상 평가에서만 갱신, 앞으로 건너뛴 시각은 정상. 결정표 순위 2에 시각 오류 포함 명시 | SRS SWR-022, 부록 A, ARC 4장 |
| AR-27 | 낮음 | 1.2절 일반 규칙과 충돌 판정 문면 충돌 | 반영: 1.2절에 충돌 판정 예외 명시 | SRS 1.2절 |
| AR-28 | 낮음 | A-02 용어, 베이스라인 ID | 반영: A-02 정정, BL-SWR-1.1 | SRS |
| AR-29 | 낮음 | DR 문구가 외부 import까지 금지, controller·runner 규칙 없음 | 반영: DR은 내부 import로 한정, 외부 허용 목록, DR-8, runner 대기 수단 | ARC 2.2, 2.1 |
| AR-30 | 낮음 | 이벤트 조회가 락 밖 | 반영: 이벤트 조회도 runner `events()`로 통일, web→event_log 의존 제거 | ARC 2.1, 2.2, 2.4 |
