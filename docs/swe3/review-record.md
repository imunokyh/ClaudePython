# 검토 기록 — SWE.3 SW 상세 설계

| 항목 | 내용 |
|---|---|
| 문서 ID | SWE3-REV |
| 검토 대상 | SWE3-DD (초안) |
| 상위 입력 | SWE1-SRS 1.1, SWE2-ARC 1.0 |
| 검토 방식 | 작성자와 분리된 독립 검토 (새 AI 에이전트, 작성자 판단을 전달하지 않음) |
| 검토 관점 | 결정표 D-01~45·P-01~10 손 계산, SWR-006/007/008/013/022 수용기준 시나리오 추적, 간섭 배제 반영, 복잡도·정의되지 않은 동작 |
| 검토일 | 2026-11-26 |
| 결과 | 17건 (높음 1, 중간 7, 낮음 9). 전부 반영. 결정표 55행은 모두 일치(DD-04 해석 전제) |

실제 사람의 서명이 아니며, OEM 승인을 뜻하지 않는다. 반영분은 작성자가 확인했고 검토자의 재확인은 받지 않았다. 반영한 동작은 4단계 단위 테스트(결정표 55행 전부 포함)로 검증한다.

| ID | 심각도 | 요지 | 처리 | 반영 위치 |
|---|---|---|---|---|
| DD-01 | 중간 | "이후 평가"를 타임스탬프로 판정해 스냅샷 없는 주기의 재입력이 override가 안 됨 | 반영: 평가 번호로 판정, 10.0초만 명령 시각 | DD 2.4, 4 |
| DD-02 | 높음 | 큰 정수 `float()` 변환 `OverflowError`가 ASIL B 경로·주기 스레드를 멈춤 | 반영: 변환 실패는 형식 오류, `tick` 예외 시 출력 유지·카운터 | DD C-3, 5.2 |
| DD-03 | 중간 | 명령만 보낸 POST가 우편함 스냅샷을 지움 | 반영: `has_snapshot` 인자 | DD 5.2, 8 |
| DD-04 | 중간 | state의 DEGRADED 판정 기준 불명확 | 반영: 조건식으로 명시 | DD 2.5 `_state_of` |
| DD-05 | 중간 | `values=None`일 때 속성 참조 오류, 시각 오류 경로 입력 미정의 | 반영 | DD 2.5, 4 |
| DD-06 | 중간 | QM 반환값 모양 검사 없음, `StrEnum` 문자열 동등 비교로 검사 통과 | 반영: controller에서 정규화, 정확한 타입 검사(C-5) | DD C-5, 2.5, 4 |
| DD-07 | 중간 | 시각 오류 평가가 기록되지 않음 | 반영 | DD 4 |
| DD-08 | 중간 | 복잡도 10 초과 예상 함수 다수 | 반영: 보조 함수로 분할 설계 | DD 2.1, 2.3, 2.4, 2.5, 3.1 |
| DD-09 | 낮음 | PENDING 타이머에 타임스탬프 유효 요구 | 반영: `crash_status` 유효만 요구 | DD 2.3 |
| DD-10 | 낮음 | NaN 시각으로 단조 검사가 꺼짐 | 반영: 유한하지 않은 시각은 시각 오류 | DD 4 |
| DD-11 | 낮음 | ARC 2.3과 인터페이스 차이, 상태 타입 불변성 미명시 | 반영: 차이표(8장), C-4 | DD 0, 8 |
| DD-12 | 낮음 | 열거형 값, 시그니처, 순위 7 이름 미명시 | 반영: 값 명시, SRS 1.4 개정 | DD 1.1, 2.1, SRS 1.2 |
| DD-13 | 낮음 | `override_active` 계산 위치, `frozen` 타입 | 반영 | DD 4 |
| DD-14 | 낮음 | 주기 초과 후 마감 계산, async 엔드포인트의 락 대기 | 반영: 마감 계산식, `run_in_threadpool` | DD 5.2, 6 |
| DD-15 | 낮음 | `snapshot: null`, `commands: null` 처리 | 반영: null 스냅샷은 형식 오류로 넘김, null 명령은 빈 목록 | DD 6 |
| DD-16 | 낮음 | 같은 순위 제안 여러 개일 때 선택 | 반영: 목록에서 먼저 나온 것 | DD 2.5 |
